# TOR POS v0.7.33 R6 – Warengruppen-Farben

- Jede Warengruppe besitzt weiterhin eine eigene, persistent gespeicherte `TileColor`.
- Farbauswahl im Stammdaten-/Warengruppen-Editor auf 48 Schnellfarben erweitert.
- Zusätzlich kann der Kunde jeden gültigen HEX-RGB-Wert `#RRGGBB` frei eingeben (praktisch 16,7 Mio. Farben).
- Sofortige Farbvorschau bleibt erhalten.
- Hauptkasse übernimmt die gespeicherte Farbe direkt für die jeweilige Warengruppen-Taste.
- Textfarbe der Warengruppen-Taste wird abhängig von der Helligkeit automatisch hell/dunkel gewählt, damit auch frei gewählte helle Farben lesbar bleiben.

Ziel: Kunde kann die Oberfläche nach eigener Logik organisieren, z. B. Getränke blau, Speisen rot, Menüs grün – ohne feste TOR-Farbvorgabe.
