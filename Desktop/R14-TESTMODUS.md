# R14 – Unlizenzierter Testmodus

Nur fuer die v0.7.33 Source-Candidate/Testphase:

- Ohne Kundenlizenz bleiben BAR/KARTE als **TEST** bedienbar.
- BAR oeffnet den kompletten Rueckgeld-Dialog.
- KARTE simuliert den Abschluss ohne ZVT-Terminalbuchung.
- In diesem Modus wird **keine echte/fiskale Sale-Buchung** geschrieben.
- Mit aktiver Lizenz bleibt der normale Produktionspfad unveraendert.
- Vor einer Produktionsfreigabe muss dieser Development-Testmodus deaktiviert werden.
