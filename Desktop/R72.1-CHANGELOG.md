# TOR POS R72.1 – Safety Migration Hotfix

## Root cause
TorPos.SafetyTests ana test DB'sini doğrudan:
`await db.InitializeAsync();`
ile açıyordu.

R69'dan beri bu metot yalnızca legacy compatibility bootstrap'tır.
R71/R72 kolonları ise SchemaMigrationService üzerinden gelir.

Bu yüzden testte:
`SQLite Error 1: no such column: s.list_subtotal_cents`
oluştu.

## Fix
SafetyTests ana DB artık gerçek uygulamayla aynı yolu kullanıyor:
`SchemaMigrationService.InitializeDatabaseAsync()`.

Böylece SaleRepository çalışmadan önce migration'lar V4'e kadar uygulanır.

## False-success fix
Eski BAT:
`if errorlevel 1`

kullanıyordu.

Windows'ta bazı .NET unhandled exception exit code'ları signed negatif
değer olarak dönebilir. Negatif değer `errorlevel >= 1` şartını sağlamadığı için
crash sonrası yanlışlıkla:
`Sicherheitstests erfolgreich`
yazılabiliyordu.

R72.1 artık sadece:
`exit code == 0`
ise başarı sayar.

Her non-zero değer:
`SICHERHEITSTESTS FEHLGESCHLAGEN`
