# TOR POS R72.3 – Safety Fixture Schema Hotfix

## Fehler
R72.2 scheiterte in R49ReviewTests mit:

`SQLite Error 1: table parked_receipt_items has no column named list_unit_price_cents`

Der Haupttest wurde bereits über SchemaMigrationService geöffnet.
Mehrere ältere Einzeltests hatten aber eigene Testdatenbanken weiterhin nur mit
`SqliteDatabase.InitializeAsync()` erstellt.

Seit R69 ist InitializeAsync nur der Legacy-Kompatibilitäts-Bootstrap.
Spalten aus R70/R71/R72 werden ausschließlich durch geordnete Migrationen
installiert.

## Dauerhafte Lösung
Neue zentrale Hilfe:
`SafetyDatabase`

Normale Testdatenbank:
`await SafetyDatabase.CreateCurrentAsync(path);`

Erneuter Start einer bestehenden normalen Testdatenbank:
`await SafetyDatabase.EnsureCurrentAsync(db);`
