# TOR POS R66.1 – Installer Hotfix

## Düzeltilen kritik hata
R66 `1-SETUP-ERSTELLEN.bat` içinde local staging bloğu yanlış konumdaydı.
Bu nedenle publish başarılı olsa bile script staging koduna düşebiliyor ve
`USB-Laufwerk erkannt: C:` gibi hatalı mesaj üretip Robocopy 16 ile durabiliyordu.

## Yeni davranış
- Kaynak `%SystemDrive%` üzerindeyse doğrudan build edilir.
- Kaynak başka bir sürücüdeyse (USB/harici/ikincil sürücü) build başlamadan
  önce `%LOCALAPPDATA%` altına kopyalanır.
- Robocopy başarısız olursa log artık ekranda ve `%TEMP%` altında görünür.
- Local staging asla publish sonrası yanlışlıkla tetiklenmez.
- Inno Setup Restart Manager otomatik uygulama kapatma taraması kapatıldı.
- TOR POS açık mı kontrolü kurulumdan hemen önce tekrar yapılır.
- Sıkıştırma `lzma2/fast` yapıldı; Setup build/install süresi azaltılır.
- USB'den hazır Setup çalıştırmak için
  `3-INSTALLATION-VOM-USB-SCHNELL.bat` eklendi.
- Build süreleri `TOR-POS-build-timing.txt` dosyasına yazılır.

## Windows kabul testi
1. C: üzerindeki projede `1-SETUP-ERSTELLEN.bat`:
   `Build-Ort: C: (direkt - kein USB-Staging notwendig)` görülmeli.
2. USB D:/E: üzerinde:
   `Nicht-Systemlaufwerk erkannt` ve local workspace görülmeli.
3. `USB-Laufwerk erkannt: C:` mesajı ASLA görülmemeli.
4. Açık TOR POS ile Setup çalıştırılırsa kurulum başlamadan temiz uyarı gelmeli.
5. TOR POS kapalıyken genel Restart-Manager
   `Das Setup konnte nicht alle Anwendungen automatisch schließen` penceresi
   çıkmamalı.
6. `7-SICHERHEITSTESTS.bat`: hedef `ALL 246 CHECKS PASSED`.
