# TOR POS R67.1 – TSE Diagnose Hotfix

## Düzeltilen build hatası
Windows build R67'de `DiagnosticsWindow.cs` içinde `TseProbeResult.Success`
kullanıldığı için CS1061 ile duruyordu. `TseProbeResult` modelinde başarı alanı yok;
durum `State` (`NotConfigured`, `SdkMissing`, `NotFound`, `Connected`, `Ready`, `Error`)
üzerinden taşınıyor.

## Yeni eşleme
- Ready -> BEREIT (yeşil)
- Connected -> VERBUNDEN · NOCH NICHT BEREIT (sarı)
- SdkMissing -> SDK FEHLT (sarı)
- NotFound -> NICHT GEFUNDEN (sarı)
- Error -> FEHLER (kırmızı)
- NotConfigured -> NICHT EINGERICHTET (sarı/pasif)

## Uyarı temizliği
Avalonia 12'de deprecated olan `TextBox.Watermark` kullanımları `PlaceholderText`
ile değiştirildi. Z-Bericht yolundaki iki nullability uyarısı da güvenli boş-string
normalizasyonu ile temizlendi.

## Test hedefi
Yeni davranış mevcut R67 test kapsamını değiştirmez. Windows hedefi:
`ALL 250 CHECKS PASSED`.

Not: Bu ortamda .NET SDK yoktur; gerçek Windows compile kullanıcı bilgisayarında
doğrulanacaktır.
