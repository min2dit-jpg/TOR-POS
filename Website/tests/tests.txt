# Tests

## Test 1 - Public test version opens without an access code [sanity]
Viewport: desktop
Covers: public test access, POST /api/site, visible test-version labeling, no private access gate, TOR POS brand logo, filled hero right panel
Description: Verifies the TOR POS development preview is publicly accessible while clearly marked as a test version.
Steps:
1. Open the public site in a fresh browser session
2. Observe the first screen
3. Inspect the page head/robots behavior
Expected: No access-code form is shown. The TOR POS homepage loads directly and a prominent TEST- / AUFBAUPHASE banner states that the site is still being built and currently accepts no sales, no orders, no contracts and no paid services. The supplied TOR POS logo is visible in the navigation and prominently in the hero's right-side brand panel, which also contains feature badges and the cashier preview instead of unused whitespace. A second WICHTIGER HINWEIS notice in the hero explains that displayed prices, products and workflows are for demonstration/testing only. The page remains noindex/nofollow.
