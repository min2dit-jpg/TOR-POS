# Legacy root files

Bu klasör, repository kökünde birikmiş eski TOR POS geliştirme dosyalarını
saklar. Dosyalar silinmedi; kökten buraya taşındı ve orijinal blob içerikleri
korundu.

Kapsam:
- eski `START-Rxx.bat` geliştirici başlatıcıları,
- eski `0-BURADAN-BASLA-Rxx.txt` notları,
- R54–R62 döneminden kökte kalmış inceleme/changelog belgeleri.

Bu dosyalar **güncel çalıştırma veya sürüm talimatı değildir**.

Güncel bilgi için:
- `../../README.md`
- `../../CHANGELOG.md`
- `../../Desktop/README.md`
- `../../Desktop/src/TorPos.Core/ReleaseInfo.cs`

Güncel geliştirici komutları `../../Desktop/` altındaki numaralı .bat
dosyalarındadır.
