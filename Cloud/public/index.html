TOR POS Cloud

Die Kasse online verfolgen – ohne die Kasse vom Internet abhängig zu machen.

TOR POS bleibt lokal arbeitsfähig. Synchronisierte Ereignisse werden über die TOR Cloud API in das Kundenportal übertragen. Das Portal startet bewusst als Lesesicht; abgeschlossene Kassendaten werden dort nicht verändert.
