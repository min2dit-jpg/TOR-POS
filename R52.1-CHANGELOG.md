# TOR POS R52.1 – Admin Setup / Login sadeleştirme

- Setup `PrivilegesRequired=admin` ile doğrudan yükseltilmiş kurulum ister.
- Kullanıcının ayrıca sağ tık -> Yönetici olarak çalıştır seçmesi gerekmez.
- Windows UAC onayı işletim sistemi güvenlik kuralıdır; sessizce atlanmaz.
- `UsePreviousAppDir=yes`: güncelleme mevcut TOR POS kurulum klasörünü kullanır.
- Setup karşılama/hazır sayfaları kaldırıldı; güncelleme daha az tıklama gerektirir.
- Anmeldung ekranındaki DE/TR/EN dil seçici tamamen kaldırıldı.
- Çoklu dil özelliği silinmedi; Programmsprache ayarı Einstellungen içinden yönetilmeye devam eder.
- Bon/Küchenbon/Abholschein/rapor/fiskal metinler Almanca kalır.
